# 字段字典

> 2026-11-04 核验本地库。每张录入表一节，省略 id 与创建、修改时间；说明写“自动”的是页面里只读的计算字段。表的用途见《数据结构说明》。

## 公司 `vi_company_base`

研究对象。业务量/单价的名称和单位在这里定义，估值模型统一用“业务量×单价＝收入”。

| 字段 | 含义 | 说明 |
|---|---|---|
| `code` | 证券代码 | 如 600900.SH |
| `name` | 公司名称 |  |
| `exchange` | 交易所 |  |
| `industry` | 行业 |  |
| `currency` | 记账币种 | 金额统一为该币种亿元 |
| `volume_label` | 业务量名称 | 收入驱动的“量”，如发电量、销量 |
| `volume_unit` | 业务量单位 | 如 亿千瓦时 |
| `price_label` | 单价名称 | 收入驱动的“价”，如综合电价 |
| `price_unit` | 单价单位 | 如 元/千瓦时；业务量×单价应等于收入（亿元） |
| `is_default` | 驾驶舱默认展示 | 已不再使用：每家公司在自己的菜单下都有驾驶舱 |
| `profile` | 公司简介 |  |
| `notes` | 备注 |  |
| `price_metric_id` | 股价指标 | 关联vi_metric_base；驾驶舱和估值结论读取的股价来自这个指标 |
| `price_fx_metric_id` | 股价汇率指标 | 关联vi_metric_base；股价币种与记账币种不同时填写（如港股、美股）：该指标的值＝1 单位股价币种折合多少记账币种；不填＝股价不换算 |
| `scope_breaks` | 口径变化年份 | 并表范围或披露口径变化的年份（如 2016、2023），历史年度里这些年与上一年不算同比 |
| `pe_ttm` | 市盈率TTM | 市场口径（A 股东方财富、港股百度股市通），由 tools/pe_pb.py 经 akshare 写入；驾驶舱顶部显示 |
| `pb` | 市净率 | 同上，市场口径的最新市净率 |
| `pe_pb_date` | 市盈率/市净率日期 | 上面两个数对应的交易日 |
| `latest_price` | 最新股价（元） | 自动；股价指标最近一个有效观察值；填了汇率指标时已折成记账币种 |
| `latest_price_date` | 最新股价日期 | 自动 |
| `latest_price_raw` | 最新股价（原币） | 自动；股价指标的原始值（未换算） |
| `latest_fx` | 折算汇率 | 自动；股价日或之前最近一个有效汇率；不需换算时为空 |
| `macro_used` | 用到的宏观数据 | 自动；自动汇总：估值参数、股价汇率、重点跟踪和订阅用到的宏观指标，括号里是用途 |

多对多：订阅的宏观数据 → vi_metric_base（`vi_lnk_company_macro_metrics`）

|---|---|---|
| `title` | 标题 |  |
| `source_type` | 类型 | 可选：定期报告、临时公告、官方网站、数据库取数、研究方法、研究推导、旧系统迁移 |
| `publisher` | 发布方 |  |
| `publish_date` | 发布日期 |  |
| `url` | 链接 |  |
| `reliability` | 可靠性 | 可选：一级·法定披露、二级·官方统计、三级·第三方数据、研究推导 |
| `verify_status` | 核验状态 | 可选：已读原文、数值已核对、待核验、仅定位入口 |

| `summary` | 内容摘要 |  |

| `company_id` | 公司 | 关联公司；留空表示通用来源（如方法论、宏观数据） |

## `vi_event_base`

名称用短名词短语，不带数字；简介三五句讲清来龙去脉、关键条款和现状。每个侧面（日期、来源、核验状态各自独立）记在定性事实里，上层判断引用侧面；零散的一次性事实可以不挂事项。

| 字段 | 含义 | 说明 |
|---|---|---|
| `name` | 事项 | 短名称，不带数字，如“喜马拉雅收购” |
| `category` | 类别 | 可选：经营、财务、资本开支、分红、债务、政策、治理、竞争、估值方法、其他 |
| `status` | 状态 | 可选：进行中、已完成、持续、待观察 |
| `period` | 时间 | 发生或持续的时间，如 2026、2018—2025 |
| `summary` | 简介 | 三五句讲清来龙去脉、关键条款和现状；细节看下面的各个侧面 |
| `company_id` | 公司 | 关联公司；这条记录属于哪家公司 |
| `fact_count` | 侧面数 | 自动；挂在这个事项下的定性事实条数 |
| `latest_as_of` | 最近日期 | 自动；各侧面截至日期的最大值 |

## `vi_fact_base`

一条可核验的定性事实，通常是某个事项的一个侧面。按期重复的数字不放这里：它们在「指标／数据」里，上层判断用“依据指标”引用；一次性的数字（并购对价、回购额度）可以写进事实。

| 字段 | 含义 | 说明 |
|---|---|---|
| `title` | 侧面 | 短名称，说明是事项的哪个侧面，如“交易对价与商誉” |
| `category` | 类别 | 可选：经营、财务、资本开支、分红、债务、政策、治理、水文、估值方法、其他 |
| `statement` | 陈述 | 写清这个侧面发生了什么、关键数字与出处 |
| `period` | 所属期间 | 如 2025、2026Q3 |
| `as_of` | 截至日期 |  |
| `verify_status` | 核验状态 | 可选：已核验、待核验、建议值待核验 |
| `notes` | 备注 |  |
| `company_id` | 公司 | 关联公司；这条记录属于哪家公司 |
| `source_id` | 来源文档 | 关联来源文档 |
| `event_id` | 所属事项 | 关联vi_event_base；这条事实是哪个事项的一个侧面；零散的一次性事实可以留空 |

| 字段 | 含义 | 说明 |
|---|---|---|
| `code` | 业务编号 |  |
| `name` | 业务名称 |  |
| `boundary` | 业务边界 |  |
| `cost_allocation` | 费用分摊依据 |  |
| `asset_boundary` | 经营资产与投入边界 |  |
| `sort` | 排序 |  |
| `company_id` | 公司 | 关联公司；这条记录属于哪家公司 |

## 商业模式拆解 `vi_biz_model_base`

商业模式画布 9 项，每块业务一项一行（B1—B9 按画布顺序）；所属业务留空表示集团整体或共性，不表示自动继承。投资者关心的内容放进画布：盈利公式的收入一侧、收入结构、单价、增长与周期写在“收入来源”；盈利公式的成本一侧、成本构成、单位利润、资本需求与现金循环写在“成本结构”。只写事实与机制；有争议、决定价值的判断写在核心论点里。

| 字段 | 含义 | 说明 |
|---|---|---|
| `code` | 编号 | B1—B9，按画布顺序；在公司和所属业务内唯一 |
| `element` | 要素 | 客户细分：卖给谁｜价值主张：为什么买｜渠道通路：怎么触达和交付｜客户关系：怎么留住、合同与结算方式｜收入来源：收入公式（量×价）、结构、单价、增长与周期｜核心资源：不可或缺的资产与能力｜关键业务：公司自己做的事｜重要合作：控股股东、供应商、伙伴｜成本结构：成本构成、经营杠杆、单位利润、资本需求与现金循环；可选：客户细分、价值主张、渠道通路、客户关系、收入来源、核心资源、关键业务、重要合作、成本结构 |
| `title` | 要点 |  |
| `content` | 说明 |  |
| `metric` | 关键数字 | 如 毛利率 44%；ARPPU 11.9 元 |
| `trend` | 变化与风险 |  |
| `company_id` | 公司 | 关联公司；这条记录属于哪家公司 |
| `business_id` | 所属业务 | 关联业务分部；留空＝集团整体或共性；业务与本记录必须属于同一公司 |

多对多：依据事实 → vi_fact_base（`vi_lnk_biz_model_facts`）；依据指标 → vi_metric_base（`vi_lnk_biz_model_basis_metrics`）

## 产业链与五力 `vi_value_chain_base`

上下游各环节是谁、拿走多少利润、对公司的议价力强弱；每行同时标注属于波特五力中的哪一种力量。同业、替代品、潜在进入者这几行只评估力量强弱，具体对手的规模与打法写在竞争对手表，并在“相关对手”里关联。

| 字段 | 含义 | 说明 |
|---|---|---|
| `code` | 编号 | V1 固定是本公司环节，其余各方从 V2 起编 |
| `position` | 环节 | 可选：上游供给、本公司环节、下游客户、渠道与流量、互补方、替代品、潜在进入者、同业竞争、监管 |
| `participant` | 参与者 |  |
| `role` | 提供或购买什么 |  |
| `force` | 五力归类 | 可选：供应商议价能力、买方议价能力、新进入者威胁、替代品威胁、行业内竞争、不适用 |
| `power` | 力量强弱 | 可选：强、中、弱 |
| `effect` | 对公司 | 可选：有利、中性、不利 |
| `trend` | 趋势 | 可选：增强、稳定、减弱 |
| `profit_share` | 利润池或成本占比 | 如 版权成本约占收入 45%—55% |
| `analysis` | 分析 |  |
| `counter` | 反面证据 |  |
| `company_id` | 公司 | 关联公司；这条记录属于哪家公司 |

多对多：依据事实 → vi_fact_base（`vi_lnk_value_chain_facts`）；依据指标 → vi_metric_base（`vi_lnk_value_chain_basis_metrics`）；相关对手 → 竞争对手（`vi_lnk_value_chain_competitors`）

## 竞争壁垒 `vi_moat_base`

每一项候选壁垒：机制、财务体现、证据、反证、复制难度；看起来像壁垒其实不是的（伪壁垒）也要列出。壁垒能不能持续，在核心论点里正反论证并关联到这里。可设自动检查，读取历史年度。

| 字段 | 含义 | 说明 |
|---|---|---|
| `code` | 编号 | 如 M1 |
| `title` | 壁垒 |  |
| `moat_type` | 类型 | 可选：成本优势、品牌与定价权、转换成本、网络效应、规模经济、牌照与资源、工艺与组织、数据与算法、生态与渠道 |
| `verdict` | 判定 | 可选：真实壁垒、局部优势、伪壁垒、待验证 |
| `strength` | 强度 | 可选：强、中、弱、无 |
| `trend` | 趋势 | 可选：增强、稳定、削弱 |
| `mechanism` | 机制 | 为什么能带来超额回报 |
| `financial_link` | 财务体现 | 体现在哪个指标：更高 ROIC 或毛利率、更高留存、更低获客成本、更稳定的现金流 |
| `evidence` | 证据 |  |
| `counter` | 反证 |  |
| `replication` | 复制难度 | 竞争者复制需要多少时间、资本、组织能力和客户验证 |
| `threats` | 削弱因素 | 新技术、监管、竞争者行为 |
| `check_metric` | 自动检查·指标 | 从历史年度取值；留空表示不做自动检查；可选：业务量、单价、营业收入、归母净利润、派息率、财务费用、业务量同比、单价同比、营业收入同比、财务费用同比、毛利率、ROE、经营现金流÷归母净利润、资本开支÷经营现金流、净负债、净负债÷EBITDA |
| `check_op` | 自动检查·条件 | 可选：<、<=、>、>= |

| `company_id` | 公司 | 关联公司；这条记录属于哪家公司 |
| `check_latest_year` | 最近年度 | 自动 |
| `check_latest_value` | 最近值 | 自动 |
| `check_result` | 自动检查结果 | 自动；未设置 / 数据不足 / 未触发 / 已触发 |
| `debate_count` | 已辩论的论点数 | 自动；关联到这项壁垒、且填了辩论日期的论点条数 |
| `debate_winner` | 论点裁决 | 自动；关联到这项壁垒、填了辩论日期的论点及其裁决（按编号，如“T1 成立；T4 观察”） |

多对多：依据事实 → vi_fact_base（`vi_lnk_moat_facts`）；依据指标 → vi_metric_base（`vi_lnk_moat_basis_metrics`）；相关论点 → 核心论点（`vi_lnk_moat_theses`）

## 核心论点 `vi_thesis_base`

决定价值的几个关键判断，每条都正反论证：正方立论、反方立论、互相反驳，再给裁决、把握、改判条件和对模型的影响。判断只写这里：没有答案的判断性问题也写成论点，缺的证据写进“决定胜负的证据”，不进“待办清单”。壁垒能否持续的论点关联到竞争壁垒（伪壁垒以外每项壁垒至少一条辩论过的论点）；能量化的改判条件设自动检查，读取历史年度。

| 字段 | 含义 | 说明 |
|---|---|---|
| `code` | 编号 | 如 T1 |
| `title` | 论点 | 写成一个可以被证伪的判断 |
| `category` | 类别 | 不利事件本身写在风险分析；这里只放有争议、决定价值的判断；可选：经营、财务、治理、估值 |
| `bull_case` | 正方立论 | 为什么成立、怎么影响现金流，附证据 |
| `decisive_evidence` | 决定胜负的证据 | 下一步要看哪些数据，包括还没取得、需要去找的证据 |
| `bear_case` | 反方立论 | 反证与边界：什么情况下不成立或被高估 |
| `verdict` | 裁决理由 |  |
| `status` | 裁决 | 成立＝正方占优；观察＝势均力敌或证据不足；存疑＝反方占优；证伪＝改判条件已经出现；可选：成立、观察、存疑、证伪 |
| `mind_changer` | 改判条件 | 什么情况下改判；能量化的同时填下面的自动检查 |
| `check_metric` | 自动检查·指标 | 从历史年度取值；留空表示不做自动检查；可选：业务量、单价、营业收入、归母净利润、派息率、财务费用、业务量同比、单价同比、营业收入同比、财务费用同比、毛利率、ROE、经营现金流÷归母净利润、资本开支÷经营现金流、净负债、净负债÷EBITDA |
| `check_op` | 自动检查·条件 | 可选：<、<=、>、>= |
| `check_threshold` | 自动检查·阈值 | 比率类填小数：-0.03 表示 -3% |
| `check_years` | 自动检查·连续年数 | 最近连续几年都满足条件才算触发 |
| `company_id` | 公司 | 关联公司；这条记录属于哪家公司 |
| `confidence` | 把握 | 可选：高、中、低 |
| `bull_rebuttal` | 正方反驳 |  |
| `bear_rebuttal` | 反方反驳 |  |
| `model_impact` | 对模型的影响 | 只写关联之外的说明（如“不改参数，只跟踪”）；对应哪条假设依据在假设依据的“相关论点”里关联，状态自动汇总在“假设依据（状态）” |
| `external_view` | 外部观点 | 卖方、外资、岗底斯观点 PK 的正反观点摘要；裁决仍由自己负责 |
| `debated_on` | 辩论日期 | 做完正反立论与互相反驳后填写；竞争壁垒的“已辩论的论点数”按它统计 |
| `check_latest_year` | 最近年度 | 自动 |
| `check_latest_value` | 最近值 | 自动 |
| `check_result` | 自动检查结果 | 自动；未设置 / 数据不足 / 未触发 / 已触发 |
| `judgment_status` | 假设依据（状态） | 自动；关联到这条论点的假设依据及其状态（按编号，如“J-P 已采纳；J-TV 研究规则”） |

## 风险分析 `vi_risk_base`

会让这笔投资亏钱的不利事件：传导路径、可能性×冲击（自动定级）、量化影响、缓冲因素、在估值里怎么处理、预警信号与触发后应对。风险是论点失败或外部冲击的“事件”，论证本身仍在核心论点里，这里只关联会被削弱的论点；落到参数的关联假设依据，盯哪些数关联预警指标。

| 字段 | 含义 | 说明 |
|---|---|---|
| `code` | 编号 | 如 R1 |
| `title` | 风险 | 写成会发生的不利事件，如“连续枯水：年发电量两年以上低于 2,700 亿千瓦时” |
| `category` | 类别 | 可选：行业与竞争、技术与替代、经营与执行、财务与资产质量、政策与监管、治理与资本配置、宏观与环境、估值与市场 |
| `mechanism` | 传导路径 | 从事件到收入、利润、现金、估值的路径 |
| `probability` | 可能性 | 未来三年内发生的可能性；可选：高、中、低 |
| `impact` | 冲击 | 发生后对每股价值的冲击：高＝超过 20%，中＝5%—20%，低＝5% 以内；可选：高、中、低 |
| `horizon` | 时间窗口 | 可选：1 年内、1—3 年、3 年以上 |
| `trend` | 趋势 | 可选：上升、稳定、下降 |
| `impact_estimate` | 影响测算 | 能量化的写数：对利润、现金或每股价值的影响（可引用单参数试验、情景） |
| `mitigants` | 缓冲因素 | 什么能限制损失 |
| `treatment` | 估值处理 | 这项风险在估值里怎么体现；未计入的要在影响测算里说明为什么；可选：已计入基准情景、已计入悲观情景、体现在折现率或门槛、未计入估值 |
| `early_warning` | 预警信号 | 看什么、到什么程度算预警；能用数据看的，把指标关联到“预警指标”；没有指标的定性事项写成“持续跟踪：…” |

| `company_id` | 公司 | 关联公司；这条记录属于哪家公司 |
| `level` | 风险等级 | 自动；可能性×冲击（高 3、中 2、低 1）：乘积 6—9 重大，3—4 重要，1—2 一般 |
| `thesis_verdicts` | 相关论点裁决 | 自动；关联的论点及其当前裁决（按编号，如“T2 观察；T3 成立”） |

多对多：会削弱的论点 → 核心论点（`vi_lnk_risk_theses`）；估值对应的假设依据 → 假设依据（`vi_lnk_risk_judgments`）；预警指标 → vi_metric_base（`vi_lnk_risk_metrics`）；依据事实 → vi_fact_base（`vi_lnk_risk_facts`）

| `invalid` | 校验失败 | 自动；拿到了响应，但解析不出日期/数值或超出合理范围 |
| `summary` | 结果 | 自动 |

## 原始采集记录 `vi_raw_capture_base`

每次采集保存完整原始响应；解析、校验、去重全部由 SQL 视图完成，可追溯。
