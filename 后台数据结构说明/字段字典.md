# 后台字段字典

核验日期：2026-10-24。以 PostgreSQL 当前实际结构为准；中文名称优先采用 NocoBase 字段标签，其次采用数据库注释。

本文供逐字段核对。业务流程、表的分工和优化建议见“数据结构说明”。“允许空”表示数据库层是否允许 NULL，并不等于页面一定允许留空。

## 商业模式拆解 · `vi_biz_model_base`

商业模式拆解：商业模式画布 9 项，每家公司一项一行（B1—B9 按画布顺序）。投资者关心的内容放进画布：盈利公式的收入一侧、收入结构、单价、增长与周期写在“收入来源”；盈利公式的成本一侧、成本构成、单位利润、资本需求与现金循环写在“成本结构”。只写事实与机制；有争议、决定价值的判断写在核心论点里。

| `title` | 要点 | text | 是 |  |
| `content` | 说明 | text | 是 |  |
| `metric` | 关键数字 | text | 是 |  |
| `trend` | 变化与风险 | text | 是 |  |
| `company_id` | 公司（ID） | bigint | 是 | FOREIGN KEY (company_id) REFERENCES vi_company_base(id) ON DELETE SET NULL |
