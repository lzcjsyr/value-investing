# 长江电力工作台 · 每日更新

Base：`PMnCb5BsGaME0ysW21uc7pHJnDb`（飞书多维表格「长江电力投资工作台」）
表：参数字典（枢纽）/ 年度数据 / 季度跟踪 / 模型预测 / 估值结果 / 情景分析 / 敏感性 / 信息源 / 公告事件 / 论点与证伪。仪表盘「估值看板」随数据自动重算。

## 铁律
1. 模型表（参数字典、年度数据、季度跟踪、模型预测、情景分析、敏感性）禁止写入任何股价信息；股价只更新估值结果表的 当前股价_元 与 价格日期。
2. 假设类参数（参数字典中类别=模型假设）如需修改，必须在修订记录写明日期与理由，未经确认不擅自改假设。
3. 数据只信法定披露：公告与定期报告为权威源，MCP只是抓取通道；每条新数据的来源字段放链接（优先链接）。
4. lark-cli 一律 `--as user`；写记录前先 `+field-list` 确认字段；连续写入串行执行。

## 流程
1. 公告扫描：东财MCP `mx_finance_search_notice` 查询"长江电力600900 最新公告"，对照公告事件表去重。
2. 分类处理：
   - 发电量公告 → 季度跟踪新增行（期间/发电量/同比/来水评价/公告链接），同步参数字典"发电量"当前值。
   - 定期报告 → iFinD `get_stock_financials` 取营收/归母净利/折旧摊销/财务费用/经营现金流/购建现金，更新年度数据对应年份行，同步参数字典。
   - 分红公告 → TuShare `dividend` 核对，更新年度数据.股息字段与参数字典。
   - 融资/政策/重大事项 → 公告事件登记，判断影响参数并在影响参数字段关联。
3. 无风险利率：iFinD `get_edb_data` 查"中债国债到期收益率:10年"最新值 → 估值结果.十年期国债收益率；折现率r=国债收益率+风险溢价（默认3.5，可调）。
4. 股价（唯一价格入口）：TuShare `daily` 或东财行情取600900最新收盘价 → 估值结果.当前股价_元 与 价格日期。
5. 模型重算：公式字段自动。若新数据使假设失效（如来水持续异常、电价机制变化、承诺违约），提出假设修订建议+理由，确认后修改模型预测对应列或参数字典。
6. 简报（惜字如金）：①新公告及处理 ②关键参数变化 ③每股内在价值、折溢价、信号 ④论点与证伪表状态变化建议。
