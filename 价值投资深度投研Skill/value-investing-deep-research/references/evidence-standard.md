# 证据与交叉验证标准

## 1. 来源等级

### A级：法定或原始披露

- 交易所、证监会、公司官网的定期报告和公告；
- 经审计财务报表；
- 政府、统计局、行业监管机构原始数据；
- 法律法规与政策原文。

用于确认财务、股本、分部、客户集中度、重大项目和治理事实。

### B级：高质量行业原始资料

- 行业协会、商品交易所、海关、专业价格机构；
- 供应链上下游上市公司的交叉披露；
- 公司业绩会文字实录，但将前瞻表述标为管理层口径。

用于确认行业规模、价格、产能、贸易流和竞争格局。

### C级：卖方、评级与专业研究

- 券商研报、评级机构报告、专家访谈摘要。

用于获得预测样本、行业框架和争议点。不是法定事实来源。

### D级：新闻、聚合网站与二手转述

只用于发现线索或交叉核对。重要结论要回到更高等级来源。

## 2. 三轮验证

### 第一轮：口径验证

检查：

- 合并报表还是母公司；
- 收入含税与否、单位和币种；
- 报告期、季度单季还是累计；
- 股本是否经过送股、拆股、回购或转债调整；
- 分部口径是否重分类；
- 价格是收盘、前复权还是后复权。

### 第二轮：来源验证

关键事实优先找到A级来源。产业关键数据至少用两个独立来源，或一个权威原始来源加一个上下游披露。来源之间不独立时不要假装完成交叉验证。

### 第三轮：经济逻辑验证

用勾稽关系检查：

- 分部之和与合并收入；
- 利润与现金流；
- 产量、销量、库存与产能；
- 股价、股本与市值；
- 企业价值、净债务和每股价值；
- 供需判断与价格/库存/开工率。

数字能对上但经济逻辑不成立，仍不能采信。

## 3. 事实、观点和假设分层

在笔记、Excel和HTML中区分：

- `事实`：有来源、日期和口径；
- `管理层口径`：公司预测或解释，可能带激励偏差；
- `卖方预测`：研究机构估计；
- `模型假设`：研究者为估值采用的判断；
- `推论`：由多个事实推导的结论。

不要把“公司预计”“券商预计”省略成客观事实。

## 4. 卖方乐观偏差处理

至少收集两家卖方的关键预测并比较：

- 收入、利润和利润率；
- 资本开支、折旧和自由现金流；
- 新项目投产时间与爬坡；
- 目标价采用的估值年份和倍数；
- 风险是否只形式化列示。

模型基准情景不要简单取卖方平均。逐项做保守化：

- 项目投产延后一至两个季度的影响；
- 新供给压价或销量未达产；
- 毛利率回归中周期；
- 资本开支超预算；
- 营运资本和税率正常化；
- 股本摊薄、少数股东和净债务完整扣除。

记录卖方预测与模型假设的差异及原因。

## 5. 下载和命名

参考文件名使用：

```text
{来源ID}_{发布日期}_{来源机构}_{文件主题}.{扩展名}
```

例如：

```text
S01_20260331_公司_2025年年度报告.pdf
S11_20260428_某证券_2026Q1点评.pdf
```

下载后检查：

- 文件可打开、不是错误页面；
- PDF页数和标题合理；
- URL、发布日期与下载日期记入 `00_来源清单.csv`；
- 同名文件不静默覆盖。

## 6. 引用

HTML的关键事实就近放来源ID，结尾提供来源登记表和原始链接。Excel的关键输入单元格用批注记录来源、日期、口径和URL。

不要只在报告结尾堆链接，让读者无法判断哪条结论由什么证据支持。

## 7. 缺失数据

若数据无法取得：

1. 明确写“未披露”；
2. 说明使用的替代指标；
3. 给出替代方法的偏差方向；
4. 降低结论置信度；
5. 不用精确小数掩盖不确定性。
