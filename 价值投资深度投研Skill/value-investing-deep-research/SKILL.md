# 价值投资深度投研

把企业当作一项长期持有的生意，而不是一串证券代码。目标不是替公司写宣传稿，而是回答三个问题：

1. 这是不是一门可以理解、可以验证、可以长期复利的好生意？
2. 当前价格是否低于保守估计的内在价值，并留有足够安全边际？
3. 哪些事实会证明判断正确或错误？

## 开始前必须读取

完整阅读并遵循：

- `references/research-framework.md`：价值投资筛选、业务分析与估值框架。
- `references/evidence-standard.md`：来源等级、交叉验证和卖方偏差处理。
- `references/deliverable-contract.md`：项目目录、HTML、Excel和验收标准。

如果环境中有专门的股票研究、电子表格或前端设计技能，同时使用它们；本技能定义投资判断与交付合同，其他技能负责其专业实现。

## 项目入口

先识别公司全称、证券代码、上市地、报告基准日和价格基准日。若名称可能对应多只证券且无法从上下文消歧，再向用户提问。

每个公司新建独立项目文件夹：

```text
{公司简称}_{证券代码}_价值投资深度投研_{YYYYMMDD}/
├── 01_过程代码/
├── 02_参考资料/
└── 03_最终输出/
```

优先运行：

```bash
python scripts/scaffold_project.py --root <工作区> --company <公司简称> --ticker <证券代码> --date <YYYYMMDD>
```

项目根目录只保留上述三个子目录。不要把截图、缓存、日志、临时文件或检查副产物遗留在根目录或最终输出目录。

## 执行纪律与阶段落盘

深度研究很容易停在“继续搜集、继续思考”的状态。必须使用阶段性可检查产物推进，而不是用进度描述代替文件：

1. **证据检查点**：项目目录建立后，先保存来源清单、法定披露和行业材料；未实际落盘的网页或搜索结果不算证据。
2. **口径冻结点**：在继续写报告前，冻结价格日期、股本、净债务、核心历史数据、分部口径和三情景关键假设，并在过程代码或模型输入中留下可追溯记录。
3. **首次可运行交付点**：口径冻结后立即生成第一版Excel和HTML；先形成可打开、可复算的完整骨架，再补充视觉和文字，不允许把“最终一次生成”作为唯一交付节点。
4. **独立验收点**：内容完成后分别执行Excel公式/重导入检查、HTML桌面与移动视觉检查、跨文件数字对表和目录清理。

使用子代理时，按“证据搜集—模型—报告—独立QA”拆成边界清楚的任务，每个代理只负责不重叠的文件或检查结果，由主代理冻结口径并集成。不要把研究、建模、HTML和验收全部交给同一个子代理。若同一阶段连续两次只报告进度而没有新增文件，或重复出现同一个阻塞，主代理必须中断并缩小任务、改派或接管，不能无限等待。

## 核心工作流

### 1. 先做价值投资适配度判断

不要等研究写完才决定它是不是价值投资标的。先形成初判，再用证据迭代。

逐项判断：

- **长坡**：终端需求和可服务市场是否仍有足够长的增长或稳态现金流寿命？
- **厚雪**：利润池是否足够厚，行业结构是否允许优秀企业持续获得高于资本成本的回报？
- **慢变**：技术、监管、消费者偏好和替代品是否变化得足够慢，使五到十年现金流可被合理估计？
- **护城河**：成本、网络、转换成本、品牌、牌照、数据、规模或工艺壁垒是否可验证且能转化为回报？
- **再投资**：增量资本回报是否好，增长是创造价值还是吞噬现金？
- **财务与治理**：资产负债表、会计质量、关联交易、分红回购和管理层资本配置是否可信？

结论必须归入三类之一：

1. `适合价值投资复利框架`
2. `可研究，但更接近周期价值/资产价值`
3. `不符合价值投资标准`

“好公司”和“好价格”分开判断。公司不符合长坡厚雪慢变时直说，不为完成估值而强行给出买入逻辑。

### 2. 建立证据库

先下载资料，再写结论。参考资料实际保存到 `02_参考资料/`，至少覆盖：

- 最近五至十年的年度报告或可比历史财务资料；
- 最新季度/中期报告、业绩预告、经营数据和重大项目公告；
- 股本变动、分红回购、融资、关联交易和治理资料；
- 行业统计、政策、价格/价差、产能或竞争格局资料；
- 至少两份近期卖方报告（能取得时），但把它们当预测样本而非事实来源；
- 带日期的市场价格和股本口径。

在参考资料目录维护 `00_来源清单.csv`，至少记录：ID、文件名、来源机构、发布日期、下载日期、来源等级、原始URL、用途、关键页码或章节。

### 3. 先科普，再分析

假设读者不了解公司和行业。用非专业读者能理解的语言说明：

- 产业链从上游原料到下游场景如何流动；
- 核心产品是什么、解决什么问题、客户为什么付钱；
- 行业单位经济模型：销量、价格、价差、良率、开工率、获客成本、ARPU或其他真正驱动利润的变量；
- 行业竞争维度与常见术语；
- 哪些指标是收入，哪些只是产能、订单或流量，避免概念混淆。

科普的目的不是堆知识，而是让读者理解后续利润、周期和壁垒为何如此形成。

### 4. 拆解业务与商业模式

从产品和客户两个角度解释收入：

- 产品/服务分部的收入、占比、增速、毛利率和资本占用；
- 客户类型、应用场景、地域、渠道、合同结构、集中度、复购或切换成本；
- 若公司未披露客户名称，不要猜测；用客户类别、前五大客户占比和行业结构描述；
- 说明盈利公式：收入如何产生，成本由什么决定，现金何时收到，需要投入多少营运资本与资本开支；
- 区分会计利润、经营现金流和所有者收益。

商业模式应回答：公司卖什么、卖给谁、为什么能卖、为什么能赚钱、为什么现金能留下来。

### 5. 识别真正的竞争壁垒

每一项壁垒都用可证伪证据验证：

- 跨周期毛利率、ROIC、市场份额或单位成本是否优于同行；
- 优势是否能持续，是否依赖单一原料、补贴、牌照或管理者；
- 竞争者复制需要多少时间、资本、组织能力和客户验证；
- 壁垒是否被新技术、产能扩张或监管变化削弱。

同时列出“看起来像壁垒、其实不是”的因素，例如规模标签、短期高毛利、地方关系、单一爆款或景气红利。

### 6. 解释周期和变化

对于周期行业，建立驱动链：

```text
终端需求 → 库存/订单 → 产品价格 → 原料与价差 → 开工率 → 单位成本 → 利润 → 现金流 → 资本开支 → 新供给
```

区分短周期库存、三至五年产能周期和长期结构变化。不要把价格上涨本身当成原因，也不要把景气高点利润永久化。

对于非周期企业，说明增长的量、价、渗透率、留存率、门店/产能、产品组合或网络效应驱动。

### 7. 审视管理层与资本配置

检查过去五至十年：

- 承诺与实际结果是否一致；
- 资本开支、并购、分红、回购、融资和负债是否创造每股价值；
- 增长是否稀释股东、是否依赖频繁融资；
- 关联交易、少数股东损益、股权激励和治理风险；
- 每股自由现金流与每股内在价值是否增长。

### 8. 建立价值投资估值

以保守、中性、乐观三种情景建模。估值方法与商业模式匹配：

- 可预测复利企业：DCF/所有者收益为主，合理倍数与反推预期交叉验证；
- 周期企业：中周期销量、价格、价差、利润率和资本开支归一化，结合DCF、PB或重置成本；
- 多元业务：分部估值；
- 金融企业：股利折现、剩余收益或PB-ROE框架；
- 资产价值标的：资产净值并逐项折价。

至少输出：

- 下行、基准、上行情景的收入、利润、自由现金流和每股价值；
- WACC/折现率、永续增长或退出倍数敏感性；
- 当前价格隐含了什么增长和利润率；
- 合理价值区间、价值中枢和带安全边际的关注/买入区间；
- 净债务、少数股东权益、期权、可转债及送转股后的每股口径。

估值是条件判断，不是假精确。情景边界必须能映射到经营事实。

### 9. 给出可跟踪、可证伪的结论

结论必须包括：

- 价值投资适配度及理由；
- 核心判断、合理价格区间和安全边际；
- 三至五项最强证据；
- 最重要的反方论点；
- 8至12个关键跟踪指标，写明频率、阈值、数据源和触发动作；
- 哪些事件会使投资逻辑失效。

如果证据不足，使用“观察/等待验证”，不要把未知包装成确定性。

## 交付与验收

`03_最终输出/` 只保留两个文件：

1. `{公司简称}_价值投资深度报告.html`
2. `{公司简称}_财务模型.xlsx`

HTML 承担全部报告叙事；Excel 只放关键输入、历史财务、预测、估值、敏感性和校验，不复制长篇报告。

完成后：

1. 重新导入Excel，扫描公式错误，核对情景估值、股本和资产负债平衡。
2. 在桌面端和移动端打开HTML，检查首屏、长表格、图表、锚点、来源链接和Excel下载链接。
3. 逐项核对HTML与Excel的价格、股本、历史数据、预测和估值结论一致。
4. 运行：

```bash
python scripts/validate_project.py <项目目录> --json
```

只有验证通过才交付。若验证器发现结构或内容问题，修复后重跑，不要解释性忽略。

如果过程代码、参考资料或最终文件仍在生成中，不得把“研究完成”视为项目完成。完成以可打开文件和验证结果为准，不以文字进度为准。

## 边界

- 不伪造无法取得的财报、研报、客户、产能、价格或市场份额。
- 不把卖方盈利预测写成公司指引。
- 不用单一市盈率替代完整估值，也不因低PE自动判定“便宜”。
- 不给出脱离日期的“当前价格”。
- 报告是研究材料，不构成个性化投资建议；清楚披露数据截止日和方法局限。
