# 宏观数据

不属于任何公司、可被各公司共用的数据：利率、汇率、大宗商品等。指标的“所属公司”为空即为宏观数据，由本项目负责；
只和一家公司有关的（股价、三峡水位）仍挂在那家公司下。

| 指标 | 类别 | 用途 |
|---|---|---|
| 中债国债10年到期收益率 | 利率 | 五家公司估值模型的无风险利率 |
| 10年国债到期收益率（中证口径） | 利率 | 历史对照（已停更），长江电力订阅 |
| 纸浆期货收盘价（Wind 活跃合约）、纸浆期货最新价（新浪 SP0 连续） | 商品 | 太阳纸业订阅；太阳纸业 J-M 与风险 R1 的跟踪指标 |
| 港元兑人民币 | 汇率 | 腾讯音乐、小米集团把港股股价折成人民币 |

## 公司怎么用

- **估值参数**：估值模型的“无风险利率指标”、公司表的“股价汇率指标”直接选宏观指标；
- **重点跟踪**：假设依据的“跟踪指标”、风险的“预警指标”可以选宏观指标；
- **订阅**：其他想看的宏观数据，在「框架与后台 / 公司」里给这家公司勾选“订阅的宏观数据”（只能选宏观指标，数据库触发器会拒绝公司指标）。

以上三种用途由视图 `vi_company_metric` 汇总，是“哪家公司用到哪个指标”的唯一来源：
指标表的“使用公司”、公司表的“用到的宏观数据”、公司菜单里的高频数据页面、驾驶舱的“立即采集一次”都读它。

## 文件

- `seed.py` → `seed.sql`：从零重建时第一个灌入（固定 id，先于长江电力）；
- `data/base.json`：指标定义与采集配置；`data/observations.json`、`data/raw_capture.json`：高频数据与原始采集记录；
- `data/raw/`：原始下载文件（Wind EDB 纸浆期货、腾讯外汇 K 线），只作出处留存。

新增宏观指标：在「宏观数据 / 指标」新增一行（所属公司留空），再在「宏观数据 / 采集配置」配好数据源；
有历史数据要补时，把原始文件放进 `data/raw/`，用迁移写入。
