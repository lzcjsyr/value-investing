# 长江电力（600900.SH）

历史研究见 [投资逻辑与工作台手册](docs/投资逻辑与工作台手册.md)。

本项目独立运行，不依赖任何外部系统的数据。`seed.py` 只读本目录的文件，生成 `seed.sql`：

- `data/base.json`：指标、公司、来源文档、事实摘录、假设依据、财务数据、经营数据、采集配置、估值模型、情景、逐年假设、单参数试验、待办清单、变更日志及其关联；`data/data_layer.json`：重点跟踪（假设依据、风险关联的指标）与数据底稿补充（字段与 `vi_` 表一致，可直接编辑）；
- `data/observations.json`、`data/raw_capture.json`：高频数据与对应的原始采集记录；
- `analysis.py`：商业模式分析（核心论点、商业模式拆解、产业链、竞争对手、竞争壁垒、适配度），按业务键写入，也生成在线库可执行的 `analysis.sql`。

2026-10-24 之前，`seed.py` 从旧系统的迁移归档读取数据；当天把长江电力负责的数据按 `vi_` 结构导出到 `data/`，从此不再读取归档。`framework/tools/rebuild_check.py` 用项目文件在临时库从零重建五家公司，与在线库逐表核对一致（只差运行时自动采集的数据）。

`seed.sql` 使用固定 id，只用于从零重建：先执行 `framework/sql/00_reset_data.sql` 清空全部数据，再第一个灌入长江电力，然后灌入其他公司（如太阳纸业）。它不再自己清空数据库。

## 2026-10-21 迁移整理时做了什么（历史）

1. **证据账本拆成两张表**：来源文档 23 条、事实摘录 14 条。旧行里的 JSON 不再出现，数字统一放进历史财务，每行都标明来源。
2. **论点合并**：1.1 商业模式（6 条）与 V1 论点与证伪（7 条）合并为 8 条投资论点。能量化的证伪条件改为自动检查：
   - 发电量连续 2 年低于 2700；
   - 电价同比低于 −3%；
   - 财务费用同比由降转升；
   - 派息率低于 70%。
3. **V1 参数字典拆分**：
   - 事实进事实摘录；
   - 假设说明进估值模型说明；
   - 派生项（每股价值、FCFE 每股、当前股价）改由公式计算。
4. **模型逻辑修正**：
   - 综合负担率 17.34% 拆成所得税率 16.27% 与少数股东占比 1.28%（2025 年实际）；
   - 利息改为债务滚动：期初带息负债 2907.51 亿，平均债务成本按原利息路径反推为 3.02%→2.05%；
   - 归属折旧改为由少数股东占比自动计算。
5. **市场数据整理**：数值列合并为一列；同一含义、不同口径的数据分成不同指标，不拼接（中债与中证 10 年国债、直采与 Wind 三峡水位）。
6. **当时没有迁移的内容**：
   - V1 的估值结果、模型预测、情景分析、敏感性 4 张表：旧的平行模型，已被新模型取代；
   - 飞书工程类质量检查（Q10—Q12）。
