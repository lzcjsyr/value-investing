## 尚未完成的严格隔离边界

检查运行中的 2.2.29 服务端安装代码发现：`plugin-flow-engine` 将 `flowSql:runById` 注册为 loggedIn，并按请求中的模板 uid 读取 SQL 后执行。该处理器中未见按当前用户的公司范围或页面路由进行校验。

这意味着普通表 ACL 和菜单限制不能单独作为 SQL 模板入口的隔离证明。尚未执行跨公司 SQL 模板调用的利用测试；当前结论来自安装代码审查。不能把当前状态描述为已完成严格的公司隔离。
