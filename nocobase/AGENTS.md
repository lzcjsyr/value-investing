# 财报抽取

- 从公司官方披露抽取三大报表、分部数据或附注前，先读 [财报抽取与 MinerU](framework/docs/财报抽取与MinerU.md)。先检查官方结构化数据或 PDF 文本层，复杂表格可用 MinerU Precision Extract API。
- MinerU 凭证变量为 `MINERU_API_KEY`，本机值在本目录的 `.env`。只通过进程环境传递凭证，避免将值写入命令、日志或 Git。
- 长财报按 170–180 页分段提交，本项目每个分片最多 200 页。结果按原 PDF 页序合并。
- 保存官方来源、页码、报告期和原始单位，核对原文与三表勾稽关系，再按对应公司的流程更新财报快照和数据库。
